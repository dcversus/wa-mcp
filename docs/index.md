A local WhatsApp bridge that exposes messaging over MCP. The bridge holds the session (Baileys multidevice), stores history in SQLite, and serves an HTTP API; the MCP server (stdio or HTTP) speaks to your assistant. Nothing leaves your machine except WhatsApp itself.
